Block tags kept:
<h1>–<h6> — Word's "Heading 1"–"Heading 6", each kept at its exact level (Heading 7–9 cap out at h6, since HTML has no tag past h6)
<p> — body paragraphs
<img alt="..."> — src left blank, fill in after uploading to the WordPress Media Library
<table><tr><td/th> — real table markup; only the first row is <th> (bold), every other row is <td> (normal weight), with inline border styling so it still looks right once pasted into WordPress
<ul>/<ol><li> — real list markup, nested sub-lists supported
Inline formatting kept:
<strong> <em> <u> <a href> <br> <img>
Word classes, inline styles, spans, and run wrappers are unwrapped down to their content — not deleted, just de-styled. Images are placed exactly where they sit in the source (inside a paragraph, list item, or table cell), so none get missed or duplicated. Footnote bodies fall through as trailing paragraphs, without the footnote link/anchor. An image inside a heading is pulled out as its own <img> — headings never wrap an <img>.
If an image is missing from the output, check whether it's set to "In Line with Text" in Word's layout options — floating/wrap-text images can be invisible to the converter.
